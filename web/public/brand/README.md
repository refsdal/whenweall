# whenweall brand assets

The mark: three option columns with the winning one filled in ember coral (#f3562e) —
the same shape language as the vote grid. Wordmark set in Bricolage Grotesque SemiBold,
converted to vector paths (no font dependency). Generated from the master geometry in
`src/components/layout/Logo.tsx` / `public/logo.svg`.

| File                                                      | Use                                                                                            |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `mark.svg` / `mark-512.png`                               | Transparent mark, any light surface                                                            |
| `mark-white.svg` / `mark-black.svg`                       | Monochrome marks for dark / light surfaces                                                     |
| `icon.svg` + `icon-{48,120,128,180,192,256,512,1024}.png` | App icon (rounded tile, paper bg). 120 & 512 fit Google Auth Platform / OAuth consent branding |
| `icon-dark(.svg/-512.png)`                                | Dark-tile variant                                                                              |
| `icon-square(.svg/-512.png)`                              | Square tile for platforms that round corners themselves                                        |
| `wordmark(.svg/-1200.png)` / `wordmark-dark.svg`          | Horizontal lockup for light / dark surfaces                                                    |
| `og(.svg/.png)`                                           | 1200×630 social/link preview image                                                             |

Colors: ember `#f3562e`, paper `#fbfaf7`, ink `#130e0b`, neutral `#8b8178`.
